# StyleRadar — Plantilla institucional para documentos

- `plantilla-institucional-styleradar.html`: plantilla editable de marca, con portada, cuerpo, tablas y originales de los cinco personajes vinculados mediante rutas relativas del repositorio.
- `StyleRadar_Plantilla_Institucional_Editable_v1.docx`: plantilla de Microsoft Word editable que incluye logo original y captura real con los cinco personajes.

## Uso

1. Extraer esta carpeta dentro de `styleradar-frontend-v3/docs/plantillas/` sin cambiar la jerarquía.
2. Abrir el HTML en Chrome. Para modificar, editar su código o abrirlo en Microsoft Word y guardar como DOCX. Alternativamente, usar directamente el DOCX.
3. Duplicar la plantilla por entregable, sustituir todos los textos entre corchetes, insertar imágenes/diagramas pertinentes, y mantener intactas las reglas del manual de identidad.
4. En Word usar Poppins si está instalada. Revisar el PDF exportado porque la paginación depende de las fuentes locales.
5. Los archivos de logo y mascotas originales no se duplican: el HTML los busca en `../../assets/`. No generan nuevas mascotas.

**Criterio pendiente del Sprint 4:** una vez incorporada, comprobar y registrar su uso en arquitectura, marketing y presentación. La mera presencia de la plantilla no prueba su adopción por todos los documentos.
